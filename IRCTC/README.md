## 🎯 Overview
This project is a modern, responsive, and ultra-fast clone of the official IRCTC (Indian Railway Catering and Tourism Corporation) website. Built from the ground up with **Next.js** and **Tailwind CSS**, it aims to replicate the core functionality and user interface of the original platform while implementing modern web development practices and technologies.

The application provides a seamless user experience for booking train tickets, checking train schedules, and exploring various travel services offered by Indian Railways, all wrapped in a premium UI.

---

## ✨ Key Features
- **📱 Fully Responsive Design**: Flawless UI that works perfectly across desktop, tablet, and mobile devices.
- **🚄 Multi-Service Platform**: Integrated interface for trains, buses, flights, hotels, and tour packages.
- **🔒 User Authentication**: Secure login and registration system for managing travel.
- **🔍 Advanced Train Search**: Comprehensive search functionality with source, destination, date, and class options.
- **🛣️ Popular Routes**: Quick, one-tap access to frequently traveled routes.
- **🤖 Disha AI Chatbot UI**: Integrated virtual assistant interface.
- **⚡ Blazing Fast**: Optimized performance leading to perfect Lighthouse scores.

---

## 💻 Tech Stack
- **Framework**: Next.js (App Router ready)
- **Styling**: Tailwind CSS
- **State Management**: React Context API
- **Deployment**: Vercel
- **Version Control**: Git & GitHub

## 🚀 Getting Started

Experience the live application here: [**IRCTC Clone Live Demo**](https://irctc-new.vercel.app/)

### Run Locally

1. **Navigate to the IRCTC directory:**
   ```bash
   cd IRCTC
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the app:**
   Open `http://localhost:3000` in your browser.
